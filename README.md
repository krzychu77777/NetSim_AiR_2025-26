Object-oriented simulation of a factory production and package distribution network written in C++17.

Developed as part of the Object-Oriented Programming course at AGH University of Krakow.

## Overview

NetSim models the flow of packages through a configurable factory network consisting of loading ramps, workers and storehouses.

Packages are generated by loading ramps, processed by workers and eventually delivered to storehouses.

The project focuses on object-oriented design, resource management and simulation of package flow in modern C++.

## Features

- configurable factory network composed of:
  - loading ramps
  - workers
  - storehouses
- package generation at configurable intervals
- configurable worker processing times
- FIFO and LIFO package queues
- probabilistic package routing
- validation of factory topology
- loading factory structure from a text stream
- saving factory structure to a text stream
- automatic package ID management
- unit testing with GoogleTest

## Architecture

The simulation is based on three main node types:

### Loading Ramp

Generates packages periodically and forwards them to connected receivers.

### Worker

Receives packages into a FIFO or LIFO queue, processes them for a defined amount of simulation time and forwards them further through the network.

### Storehouse

Acts as the final destination for packages and stores received packages.

The `Factory` class manages all nodes, their connections and the execution of individual simulation stages.

It also verifies whether each package sender has a valid path leading to a storehouse.

## Factory Configuration

The factory structure can be loaded from and saved to a simple text format.

Example:

```text
LOADING_RAMP id=1 delivery-interval=3
WORKER id=1 processing-time=2 queue-type=FIFO
STOREHOUSE id=1

LINK src=ramp-1 dest=worker-1
LINK src=worker-1 dest=store-1
```
